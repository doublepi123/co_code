# v0.3.4 — 手机上的模型选择改成底部面板，返回键可关闭

## 改进

- **内嵌 Cox 升级到 0.1.10**：手机上的模型选择从输入框上方的小弹窗改成从底部升起的面板。顶部是提供商标签（收藏、Codex、Claude、OpenCode），中间是搜索和更大的模型列表，底部固定思考强度（Low 到 Max）、速度和权限。打开时不弹键盘，点搜索框才弹；键盘弹出时面板整体上移，仍可搜索和选择。电脑上的界面不变。
- **返回键关闭面板**：面板打开时按 Android 返回键只关闭面板，不再直接退出 App；搜索时第一次返回先收起键盘。

## 验证范围

- Android 15 / x86_64 模拟器（带 Gboard 输入法）：在 App 内把 Cox 更新到 0.1.10；输入框在屏幕中间和底部两种情况下面板完整显示；选择模型和 Max、搜索时键盘弹出、点 Done、点空白处、向下拖动都正常。
- 返回键：面板打开时按一次返回只关闭面板并停留在当前对话；用 Done 关闭后再按返回直接离开 App（没有多余的历史记录）；搜索时依次为收起键盘、关闭面板、离开 App；连续开关三次后再按返回也直接离开 App。
- Cox 0.1.10 的完整 CI 与手机布局、历史记录相关浏览器测试通过。开发与官方构建混合验证，尚未在实体手机上确认。

## English

- Embedded Cox 0.1.10: on phones the model picker is a bottom sheet with provider chips, an unfocused search field, a roomy model list and a pinned footer for effort, speed and access. Desktop is unchanged.
- Android Back closes the sheet instead of leaving the app; while searching, the first Back hides the keyboard.

Validation: on an Android 15 x86_64 emulator with Gboard, the in-app Cox 0.1.10 update ran; the sheet, search with keyboard, Done/scrim/swipe close and all Back-key sequences behaved as described. Cox 0.1.10 CI and browser tests passed. Not yet confirmed on a physical phone.
