# v1.0.3 — Cox 更新交由 CoCode 管理

## 更新

- **隐藏 Cox 自带的更新检查**：Cox 由 CoCode 负责安装和更新。App 启动本机 Cox 时会设置 `COX_UPDATES_MANAGED_BY=CoCode`，支持该变量的 Cox 会隐藏自己的更新检查，避免提示一个在 App 内无法直接执行的更新。更新 Cox 仍通过 App 中的本地环境更新完成。

## 升级方式

直接安装签名 APK 覆盖升级，无需删除项目或会话。升级后 App 下次启动 Cox 时生效。

## 验证范围

- GitHub Actions 运行全部 JVM 单元测试并构建 Debug APK；新增测试覆盖启动 Cox 时设置该环境变量。
- 未在 Android 实机上验证 Cox 界面中更新检查的隐藏效果。未调用付费推理。

## English

CoCode installs and updates Cox itself, so the app now sets `COX_UPDATES_MANAGED_BY=CoCode` when it starts the local Cox, and a Cox version that honors the variable hides its own update check. Update Cox through the app's local environment update as before.

Install the signed APK over the existing app; the change applies the next time the app starts Cox. Validation covers the JVM unit tests, including a new case for the environment variable, and the Debug APK build in GitHub Actions. Hiding the update check in the Cox UI was not verified on an Android device. No paid inference was performed.
