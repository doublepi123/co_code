# v0.2.0 — 双服务选择、配置共享与更新提示

## 新功能

- **服务端任选**：T3 Code、OpenChamber 可单独安装，也可以同时安装；同一时间运行一个，切换前会确认中断当前服务。两者共用主目录、项目和 OpenCode 配置，登录密码与 WebView Profile 分别保存。
- **App 更新提示**：打开 CoCode 时检查 GitHub Releases，包括 0.x 预发布版本；发现新版后提示前往下载，不会自动安装或打断任务。
- **新图标**：手机与终端提示符，不再使用 AndChamber 的立方体。
- **完整目录映射**：公共目录新增 `codex/ → ~/.codex`、`claude/ → ~/.claude`，保留 `opencode/ → ~/.config/opencode` 和项目映射。

## 修复

- 安装前取消唯一选中的 OpenCode 不再闪退；空选择会提示并禁止继续安装。
- 追加安装代理保留已有代理，卸载需单独确认；安装变更通过 staging 验证后切换，失败不替换旧环境。
- OpenChamber 所需的 OpenCode 显示为必需组件，不能误卸载。
- 保留 v0.1.0 的现有安装、登录和会话，服务切换使用独立端口和认证协议。
- 维护期间后到达的 Stop 不会被旧的重启请求覆盖。
- 共享目录迁移使用私有快照、恢复日志、独占创建和哈希校验；不覆盖已有公共文件，不把中断后的半截文件当作成功。

## 共享目录重要说明

**完整映射包含 Codex、Claude 的登录凭据、会话与历史记录。其他获得存储访问权限的 App 可以读取或复制它们，并使用你的账号。开启前必须勾选确认此风险。**

- 旧版已开启共享的用户仍先保持项目/OpenCode 映射；重新确认后才共享 Codex 和 Claude。
- 关闭共享不自动复制回来，可能重新看到开启前的旧私有副本；公共目录不会删除。
- `~/.claude.json`、OpenCode 的 `~/.local/share/opencode`、服务密码和插件 `node_modules`、两种服务的数据仍在私有目录。
- 不恢复手机操控、浏览器操控或代理通知快捷回复。

## 验证范围

- 533 项 JVM 测试、61 项 Python 测试通过。
- Android 15 / x86_64 模拟器：30 项设备测试通过，零跳过；验证空选择、追加安装保留、双服务界面、更新提示和真实共享存储上的迁移/原子保存。
- Android 12 / ARM64 redroid 容器：9 项存储测试通过，零跳过；OpenChamber 安装、启动、自动登录、共享 OpenCode 配置、升级策略 409 和切回 T3 均已验证，旧数据保留。
- 上述功能验证使用开发构建；不是实体手机或厂商后台策略验证。详细记录见 [验证说明](https://github.com/doublepi123/co_code/blob/v0.2.0/docs/testing-dual-server.md)。

## English

- Install T3 Code, OpenChamber, or both in one environment. One runs at a time; switching requires confirmation. They share projects and OpenCode configuration while keeping separate passwords and WebView profiles.
- Check CoCode GitHub Releases on opening and offer the download page when a newer version exists, including prereleases. No automatic installation.
- New phone/terminal icon; full Codex and Claude directory mappings alongside OpenCode and projects.
- Fix empty-agent-selection crashes, preserve existing agents when adding another, confirm removals, protect OpenChamber's OpenCode dependency, and respect later Stop requests during maintenance.
- Package changes are staged and verified before activation. Shared-folder migration uses private snapshots and recovery journals, exclusive target creation and SHA-256 verification.

**Privacy warning:** full Codex/Claude sharing includes login credentials, sessions and history. Other storage-authorized apps may copy them and access your accounts. Explicit acknowledgement is required, including when upgrading existing shared-folder users. Disabling sharing does not copy public changes back to the older private copies.

Validation: 533 JVM tests, 61 Python tests, 30 Android 15/x86_64 device tests and 9 Android 12/ARM64 redroid storage tests passed without skips. Actual ARM64 OpenChamber startup, authentication, shared configuration, policy rejection and switching back to T3 were verified on a development build. Physical phones and vendor background policies remain unverified.
