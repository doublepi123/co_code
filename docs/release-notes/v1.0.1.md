# v1.0.1 — OMO Native、Oh My Pi 与 iOS 客户端

## 更新

- **OMO Native**：可在本地环境中选择安装 `omo-ai`。版本跟随所安装 Cox 声明的 `OMO_VERSION` 锁定；查询失败时使用 5.1.69。
- **Oh My Pi**：可安装 `can1357/oh-my-pi` 官方 musl 独立二进制，按 `SHA256SUMS.txt` 校验后再启用；查询失败时使用 18.20.3。
- **Cox 备用版本**：npm 查询失败时安装 Cox 0.1.96。正常安装仍解析 npm 最新稳定版本。
- **更新检查**：检查新版本时读取全部 GitHub Release。此前只读最近 30 个，iOS 构建发布增多后可能看不到新的 Android 版本。
- **iOS 客户端**：同时发布 CoCode iOS 1.0.1（`ios-v1.0.1`）。首次启动从对应 Release 下载并校验 Linux 镜像，界面支持简体中文。

## 升级方式

直接安装签名 APK 覆盖升级，无需删除项目或会话。要使用 OMO Native 或 Oh My Pi，在 App 中更新本地环境并选择对应 Agent，然后重启 Cox。仅升级 APK 不会自动更新正在运行的 Cox。

## 验证范围

- GitHub Actions 运行全部 JVM 单元测试，并构建 Debug APK。
- 未在 Android 实机或模拟器上验证 OMO Native 与 Oh My Pi 的安装和推理。未调用付费推理。

## English

The local environment can install OMO Native (`omo-ai`, pinned to the installed Cox server's `OMO_VERSION`, fallback 5.1.69) and Oh My Pi (the official `can1357/oh-my-pi` musl binary, verified against `SHA256SUMS.txt`, fallback 18.20.3). The Cox setup fallback is 0.1.96; normal setup still resolves npm's latest stable version. The update check now reads every GitHub release instead of the latest 30, so iOS releases cannot hide a newer APK.

CoCode for iOS 1.0.1 ships alongside as `ios-v1.0.1`; it downloads and verifies its Linux image on first launch and supports Simplified Chinese.

Install the signed APK over the existing app, then update the local environment and restart Cox to use the new agents. Validation covers the JVM unit tests and the Debug APK build in GitHub Actions. OMO Native and Oh My Pi installation and inference were not exercised on an Android device or emulator. No paid inference was performed.
