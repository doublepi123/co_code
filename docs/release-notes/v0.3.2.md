# v0.3.2 — 手机上打开模型选择框不再弹出键盘

## 修复

- **内嵌 Cox 升级到 0.1.4**：在手机上打开模型选择框时，不再自动把光标放进「搜索模型」并弹出输入法键盘。之前键盘会占掉约四成屏幕，把选择框压扁，思考强度又只显示前几档。现在想搜索时点一下搜索框即可；电脑上不变。

## 验证范围

- 全部 JVM 测试通过；Cox 0.1.4 的模型选择框浏览器测试（包括模拟触屏的焦点测试和手机尺寸布局测试）与完整 CI 通过。
- rpi 上的 Android 12 / ARM64 redroid 容器：在 App 内把 Cox 0.1.3 一键更新到 0.1.4 并正常运行；打开模型选择框后搜索框没有获得焦点、没有请求输入法，五档思考强度全部可见。
- 这个容器没有屏幕键盘，「不弹键盘」本身还需要在带输入法的实体手机上确认。开发构建，不是实体手机或厂商后台策略验证。

## English

- Embedded Cox 0.1.4: on phones the model picker no longer focuses its search field on open, so the soft keyboard stays closed and every effort level stays visible. Tap the search field to search; desktop is unchanged.

Validation: JVM tests and Cox's picker browser tests (touch focus and phone layout) plus full Cox CI passed. On Android 12 / ARM64 redroid an in-app Cox 0.1.3 → 0.1.4 update ran; opening the picker left search unfocused with no IME request and all effort levels visible. That container has no soft keyboard; a physical phone check is still pending.
