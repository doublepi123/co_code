# v0.1.0 — 第一个版本：在手机上运行 T3 Code

> First release: run the T3 Code server and your coding agents on an Android phone.

CoCode 从 [AndChamber](https://github.com/doublepi123/and-chamber) v0.0.41 派生，把手机上运行的服务换成了 [T3 Code](https://github.com/doublepi123/t3code)，不需要电脑、不需要 root。

## 功能

- **本机运行 T3 Code**：首次设置时下载 Alpine Linux 和 Node.js，再从 T3 Code 的发布页下载 Android 专用服务端包（arm64 / x86_64，musl），核对 SHA-256 后安装；之后打开 App 即可使用。
- **自己选要装的编程代理**：Codex、Claude Code、OpenCode 任选一个或多个（至少一个），装好后也可以随时增减。勾选 OpenCode 时，App 会自动在 T3 Code 中启用它。
- **自动登录**：本机服务使用随机密码，App 自动登录。
- **后台常驻**、**公共目录** `/sdcard/CoCode`（可选）、**远程 T3 Code 服务器**：沿用 AndChamber 的能力。
- **更新**：检查 T3 Code 新版本和各代理的 npm 新版本，在副本中更新后原子切换，失败时保留旧环境。

## 与 AndChamber 的区别

- 去掉了手机操控和内置浏览器操控。
- 去掉了 OpenChamber 的通知快捷回复；目前只通知运行时错误。
- 包名为 `io.cocode.app`，可以和 AndChamber 同时安装。签名密钥是新的。

## 使用前须知

- 各代理的账号或 API Key 需要你自己配置（例如在 T3 Code 的终端里运行 `codex login`、`claude`，或编辑 `~/.codex`、`~/.claude`、`~/.config/opencode` 下的配置）。未配置时 T3 Code 会提示未登录。
- 首次设置需要约 1.2 GB 空间，建议使用 Wi-Fi。

## 验证范围

- x86_64：Android 15 模拟器（API 35）从零安装三个代理约 4.5 分钟，三个代理都通过 T3 Code 完成了写文件的任务，App 内对话正常。
- arm64：在 arm64 主机上的 redroid 容器（Android 12，arm64-v8a）从零安装约 6 分钟，三个代理都完成了写文件的任务，App 内会话列表正常。
- 未在真实 arm64 手机上验证；厂商后台策略、内存较小的手机未覆盖。

## Features

- **T3 Code on the phone**: first setup downloads Alpine Linux and Node.js, then the Android server bundle (arm64 / x86_64, musl) from the T3 Code releases, verified by SHA-256.
- **Pick your agents**: Codex, Claude Code and OpenCode, any combination (at least one); change the set later. Picking OpenCode enables it in T3 Code automatically.
- **Automatic sign-in**, **background service**, optional **shared folder** `/sdcard/CoCode` and **remote T3 Code servers**, carried over from AndChamber.
- **Updates**: newer T3 Code releases and agent npm versions are installed into a copy and swapped in atomically; a failure keeps the old environment.

## Differences from AndChamber

- Phone control and embedded browser control are removed.
- OpenChamber notification quick replies are removed; only runtime errors are notified for now.
- Package `io.cocode.app`, installable next to AndChamber, with a new signing key.

## Before you start

- Configure each agent's account or API key yourself (for example `codex login` / `claude` in a T3 Code terminal, or the files under `~/.codex`, `~/.claude`, `~/.config/opencode`). T3 Code reports an agent as unauthenticated until then.
- First setup needs about 1.2 GB; Wi-Fi recommended.

## Verification scope

- x86_64: Android 15 emulator (API 35), clean setup of all three agents in about 4.5 minutes; each agent completed a file-writing task through T3 Code, and chat works in the app.
- arm64: redroid container (Android 12, arm64-v8a) on an arm64 host, clean setup in about 6 minutes; each agent completed a file-writing task, and the session list shows in the app.
- Not verified on a physical arm64 phone; vendor background policies and low-memory phones are not covered.
