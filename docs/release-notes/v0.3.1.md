# v0.3.1 — Codex 登录状态不再误掉、手机上思考强度显示完整、其他电脑可排序

## 新功能

- **「其他电脑」可以调整顺序**：有两台及以上时，按住一行（会轻震）上下拖动，松手保存；也可以在每行的 ⋮ 菜单里选「上移 / 下移」，读屏软件同样可用。编辑一台电脑后它会留在原来的位置，不再跑到最后。

## 修复

- **重新打开 App 后 Codex 显示「登录」**：启动时 App 一边检查 Codex 登录状态、一边启动 Cox，启动前的旧进程清理会把正在进行的检查一起结束，App 误以为没登录（实际授权一直有效）。现在只有 Codex 明确回答「Not logged in」才显示「登录」；检查被打断会自动重试，服务启动后还会再查一次。
- **内嵌 Cox 升级到 0.1.3**：手机上选择模型时，「思考强度」的五档（Low 到 Max）会完整显示，不再被弹窗截掉；空间不够时模型列表先缩小，可以搜索或滑动。

## 验证范围

- 592 项 JVM 测试、61 项 Python 测试通过。
- Pi400 上的 Android 12 / ARM64 redroid 容器：排序和 Codex 登录界面的 16 项设备测试通过，零跳过。
- rpi 上的 Android 12 / ARM64 redroid 容器：用测试 API Key 登录 Codex 后连续 6 次冷启动 App，每次都显示「已登录」；在 App 内把 Cox 0.1.1 一键更新到 0.1.3 并正常运行；新对话里打开模型选择框，五档思考强度全部可见。测试结束后已退出登录。
- 这些验证用的是开发构建，不是实体手机或厂商后台策略验证。

## English

- Reorder saved remote servers: long-press and drag a row (with haptic feedback), or use Move up / Move down in the row menu and accessibility actions. Editing a server keeps its position.
- Fix Codex showing "Sign in" after reopening the app: the start-up status check could be killed by the server's stale-process cleanup and was read as signed out. Only Codex's explicit "Not logged in" now counts; an interrupted check is retried and re-run once the server is up.
- Embedded Cox 0.1.3: on phones the model picker keeps every effort level (Low to Max) visible instead of clipping it.

Validation: 592 JVM and 61 Python tests passed. On Android 12 / ARM64 redroid hosts, 16 device tests passed without skips; six cold starts kept Codex signed in; an in-app Cox 0.1.1 → 0.1.3 update ran and the picker showed all effort levels. Development builds; physical phones and vendor background policies remain unverified.
