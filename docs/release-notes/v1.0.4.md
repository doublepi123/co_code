# v1.0.4 — 本机 Cox 空闲时允许手机休眠

## 更新

- 搭配 Cox 0.2.38 或更新版本，本机运行时空闲后释放 Android 唤醒锁。Cox 继续在前台服务中运行，打开 App 后无需重启本地环境。
- 安装、启动、停止和实际工作期间继续持锁。Cox 在启动代理任务或终端前先等 Android 确认持锁。启用了有待运行的定时任务时，手机会继续持锁以保证任务按时执行。
- 使用旧版 Cox 时保留原有保活行为。若唤醒协议断开或收到无效消息，CoCode 会保守持锁。

## 升级方式

用签名 APK 覆盖安装，再通过 CoCode 的本地环境更新将 Cox 升到 0.2.38 或更新版本。无需删除项目或会话。

## 验证范围

569 项 Android 单元测试通过。Android 35 模拟器用真实 Cox 进程验证了旧版保活、空闲释放、终端打开前持锁和终端关闭后重新释放。未测量实体手机的续航变化。

## English

With Cox 0.2.38 or newer, CoCode releases the Android wake lock when the local runtime is idle. Cox continues to run in the foreground service. Installation, startup, shutdown, active work, and schedules with a pending run still keep the device awake. Agent turns and terminals wait for CoCode to confirm that the lock is held before starting. Older Cox versions keep their previous wake-lock behavior.

Install the signed APK over the existing app, and update Cox from CoCode's local environment settings. Projects and sessions do not need to be removed.
