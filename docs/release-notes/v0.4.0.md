# v0.4.0 — 专注 Cox 与模型中心

## 更新

- **专注 Cox**：移除 OpenChamber 的安装、启动、切换及远程协议支持。已有 Cox 数据继续使用；旧 OpenChamber 环境可重新安装为 Cox，迁移保留项目和用户目录，安装失败保留原环境。已保存的 OpenChamber 远程记录不再显示。
- **登录交给 Cox**：移除 App 原生 Codex 登录入口、登录流程和登录态检测。已有凭据不删除，后续认证在 Cox 中完成。
- **模型中心入口**：首页可直接打开 Cox 的模型中心，以及 Agent 设置与安装页面；必要时启动本地 Cox。模型中心需要 Cox 0.1.21 或更新版本，旧版本显示更新提示。
- **扩展 Agent 安装**：支持通过 npm 安装 Codex、Claude Code、OpenCode、Grok 和 Pi；Cursor 使用 Cox 内置 SDK。Antigravity 与 ACP Registry 的安装在 Cox 设置中完成；Fx、Muse 仍需按上游说明手动准备可执行文件。
- **运行环境维护**：补齐 Cox 安装器所需工具，修正 provider 默认配置并保留已有禁用和自定义设置；Cox 备用版本更新至 0.1.29，正常安装仍解析 npm 最新稳定版本。

## 升级方式

直接安装签名 APK 覆盖升级，无需删除项目或会话。若需要新版本 Cox 或新 Agent，在 App 中更新本地环境后重启 Cox。仅升级 APK 不会自动更新正在运行的 Cox。

## 验证范围

- 544 项 JVM 测试、61 项 Python 测试通过，Debug APK 与测试 APK 构建通过。
- Android 15 x86_64 模拟器通过 17 项设置入口、旧版 Cox 提示、远程记录兼容及维护界面测试。
- 本轮未完成 ARM64 Android 实机验证，也未逐一验证所有 Agent 在 Android 上的安装与推理。Cursor 内置 SDK 不等于独立 CLI；Fx、Muse 不提供自动安装。未调用付费推理。

## English

CoCode now focuses on Cox. OpenChamber installation, launch, server selection and remote protocol support are removed. Existing Cox data remains usable; replacing a retired local environment preserves projects and user directories, with staged installation and rollback on failure. Saved OpenChamber remote entries are no longer shown.

Native Codex login and login-state detection are removed; credentials are preserved and authentication belongs to Cox. Home shortcuts open Cox model services and provider settings, starting the local server when needed. Model services require Cox 0.1.21 or newer.

Install Codex, Claude Code, OpenCode, Grok and Pi through npm; Cursor uses Cox's bundled SDK. Antigravity and ACP Registry use Cox settings installers. Fx and Muse still require manually prepared upstream executables. Provider defaults preserve existing custom and disabled instances. The fallback Cox version is 0.1.29; normal setup resolves npm's latest stable version.

Install the signed APK over the existing app. Update the local runtime and restart Cox separately when needed. Validation includes 544 JVM tests, 61 Python tests and 17 Android 15 x86_64 emulator tests. ARM64 Android and every agent's Android install/inference path have not been certified in this release. No paid inference was performed.
