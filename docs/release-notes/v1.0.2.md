# v1.0.2 — 修复 Cox 误报已在运行

## 更新

- **本机 Cox 启动更可靠**：App 被系统结束或 Cox 异常退出后，再次启动时可能提示 “A Cox server is already running for /root/.cox (pid …)” 并无法打开 Cox。原因是上次运行留下的记录指向的进程号已被系统分配给其他 App。现在 App 会在确认旧服务已经停止、端口空闲之后清除这条过期记录，再启动 Cox。

## 升级方式

直接安装签名 APK 覆盖升级，无需删除项目或会话。

## 验证范围

- GitHub Actions 运行全部 JVM 单元测试并构建 Debug APK；新增测试覆盖“启动前清除过期记录”与“端口被其他程序占用时不动记录、不启动”两种情况。
- 未在 Android 实机上复现原始报错的完整场景。未调用付费推理。

## English

Starting the local Cox could fail with "A Cox server is already running for /root/.cox (pid …)" after the app or Cox had been killed: the run record left behind named a process ID that Android had since given to another app. The app now removes that stale record once its pre-start cleanup has confirmed no server of ours is running and the port is free, then starts Cox.

Install the signed APK over the existing app. Validation covers the JVM unit tests, including the new cases for removing the stale record and for leaving it untouched when another program holds the port, and the Debug APK build in GitHub Actions. The original failure was not reproduced end to end on an Android device. No paid inference was performed.
